# 7. Proposed Engagement Model

## 7.1 JV Structure Options

### Option A: Project-Based Alliance (Recommended Start)
- **Structure**: Formal partnership agreement with shared P&L per project
- **Governance**: Joint steering committee, shared project management
- **IP**: Each party retains core IP; jointly developed integrations are co-owned
- **Go-to-market**: Joint pitch teams, Sapient leads enterprise/account, VMI leads creative/3D
- **Advantage**: Low commitment, fast to execute, proves the model before deeper integration
- **Risk**: Limited exclusivity, either party can pursue similar work independently

### Option B: Dedicated JV Entity
- **Structure**: New legal entity (e.g., "Sapient x Journey Digital Twins" or similar)
- **Governance**: Board with representatives from both organisations
- **IP**: JV entity owns jointly developed platform IP
- **Go-to-market**: Dedicated sales team, branded offering
- **Advantage**: Stronger market positioning, dedicated resources, IP accumulation
- **Risk**: Higher commitment, slower to establish, requires legal/commercial alignment

### Recommendation
**Start with Option A** for the first 2-3 projects (target: Diriyah + one ROSHN community). If successful, escalate to **Option B** with a dedicated Saudi-focused entity aligned to Vision 2030.

## 7.3 Phased Delivery Approach

### Phase 1: Proof of Concept (6-8 weeks)
**Goal**: Demonstrate the combined capability with a bounded deliverable

- Capture an existing Diriyah asset via 3DGS (VMI)
- Deploy as a WebGPU viewer with AI concierge overlay (Sapient Bodhi)
- Concierge answers questions about the property in Arabic and English
- Deliver as a shareable web link — no app install required
- Measure: engagement time, questions asked, lead qualification rate

**Investment**: Modest — uses existing VMI capture pipeline + Sapient Bodhi sandbox

### Phase 2: MVP Digital Twin Sales Platform (12-16 weeks)
**Goal**: Full intelligent digital twin for one Diriyah residential district

- Unreal Engine 5.5 digital twin with Pixel Streaming 2 (VMI)
- Bodhi multi-agent system: sales concierge, analytics agent, compliance agent (Sapient)
- Interactive unit selector, floor plan explorer, finish customiser
- CRM integration (Salesforce) for availability and lead capture
- Luna analytics dashboard for sales team
- Multilingual (Arabic, English, +2)
- Web deployment — desktop + mobile

**Investment**: Significant — full project team, cloud infrastructure

### Phase 3: Scale Across Portfolio (Ongoing)
**Goal**: Replicate and extend to ROSHN, Qiddiya, NEOM

- Template the platform for rapid deployment across communities
- Add 3DGS construction progress pipeline
- Extend to visitor experience use case (Qiddiya)
- Introduce living community twin (ROSHN post-handover)
- Launch AI Content Factory for marketing automation

## 7.4 Commercial Framework

### Revenue Streams
1. **Implementation fees** — project-based delivery for each digital twin
2. **Platform license** — recurring fee for Bodhi AI + Luna analytics
3. **Managed service** — ongoing hosting, content updates, AI model refinement
4. **Content-as-a-Service** — automated marketing asset generation
5. **Per-interaction fees** — AI concierge usage-based pricing (optional)

### Revenue Split Principles (Option A)
- Implementation: split based on team contribution ratio
- Platform: Sapient leads (Bodhi), VMI leads (Luna), shared revenue on combined offering
- Managed service: shared based on delivery responsibility
- Typical range: 50/50 to 60/40 depending on project mix

### Pricing Benchmarks
- DAMAC's digital twin platform generated $400M+ in transactions — the platform investment is a fraction of sales it enables
- Enterprise AI platforms typically command $500K-$2M+ annual license fees
- Digital twin development for a single community: $300K-$1.5M depending on scope
- AI concierge managed service: $15K-$50K/month
